# CSV 双表核对服务｜99 元/次

**先确认范围和交付安排，再决定是否接单；付款渠道另行确认。本仓库没有商城或支付功能，不在 Issue 中收款或收集支付凭据。**

两份 CSV、一个匹配键、事先约定的对比列，整理相对旧表的新增、缺失及原始文本值变化，交付 HTML 差异报告、JSON 完整明细和中文核对说明。

## 服务范围

- 99 元/次：两份约定范围内的 CSV、一个匹配键、约定对比列，含一次约定范围内修正。
- 先看脱敏小样，确认 UTF-8 编码、文件大致规模、匹配键和对比目标是否可处理，再约定具体范围与交付方式。不保证任意文件量或任意格式都能处理。脱敏小样也不要贴在公开 Issue 中，交付方式另行确认。
- 重复键、空键会单列为无法核对，不擅自合并、补键、取第一条或猜配。
- 按原始文本核对，保留前导零；`010` 与 `10` 是不同键，`10` 与 `10.0` 会记为文本变化。新增/缺失仅表示这两份输入中的键集合差异，不直接证明业务增删。
- 不做数值计算、复杂公式处理、会计或财务审计。所选列一致不代表整份文件或业务一致。
- 新增文件、更换匹配规则、增加对比列需另行确认。不承诺固定交期或无限修改。

本仓库仅公开服务说明和合成样例，不提供私有核对工具源码或软件安装包。下面不是客户案例，不证明软件正式验收、支付已接通、商业运营已上线或已经成交。

## 可核验的合成样例

**全部数据完全虚构，不含真实客户信息。** 旧表9条、新表8条数据，唯一键是“编号”，只比较“名称、数量、状态”；“备注”明确不参与比较。

| 实际输出 | 数量与内容 |
| --- | --- |
| 匹配 | 4对，其中所选列一致1对、变化3对 |
| 新版新增 | 2条：`006`、`10` |
| 新版缺失 | 2条：`003`、`010` |
| 值变化 | 3处：`001`数量`10→12`；`004`状态`在售→下架`；`007`数量`10→10.0` |
| 无法核对 | 5条：左表重复`005`两条、右表`005`一条因对侧重复排除，两侧空键各一条 |
